# Length-cut prompt

Using the user-approved Long story bible below, derive coherent Medium and Short
versions of the same story. Do not change facts shared between lengths: keep
character identities and goals, truth text, and the central mystery solution
consistent.

For each length, list:
- Included locations in beat/act order.
- Included cast, core and side truths, subplots, twists, red herrings, and
endings.
- Required discoveries before each next beat opens.
- Any routes that preserve access to each core truth and key item.

Finish with a cut log that names each major element removed from Long for
Medium, and from Medium for Short, and why the shorter story remains complete.
